    ## AI 요약

    제공된 데이터의 주요 내용을 아래와 같이 요약합니다.

## # AI와 개발 생산성 향상 (`Claude Code`, `Codex`)
- **개발자의 '코드 밖의 일' 자동화**: **ClaudeCode**와 **Codex** 같은 AI를 활용하여 Jira 일감 정리, PR 검토, 문서 확인 등 코드 작성 외의 업무 효율을 높입니다.
- **레거시 백오피스 개선**: **Claude Code Skill**을 적용해 엑셀 데이터를 활용한 반복적인 다국어 처리 등의 비효율적인 업무 절차를 개선합니다.

## # Hive Axyl Plugin을 활용한 데이터 분석 (`Axyl`, `MCP`)
- **자연어 기반 지표 조회 및 대시보드 구성**: ChatGPT와 **Hive Axyl Plugin**을 연동하여 자연어로 게임 지표를 조회하고, 다수의 차트를 포함한 대시보드를 손쉽게 구성할 수 있습니다.
- **분석 범위 최적화**: 이전 대화 맥락을 유지하며 국가, 마켓, 상품 순으로 분석 범위를 좁혀 원인 후보를 빠르게 파악합니다.

## # BigQuery 및 이벤트 로그 관리 (`빅쿼리`, `애널리틱스`)
- **원본 데이터 직접 조회**: Hive 애널리틱스의 이벤트 원본 데이터는 **BigQuery**(`habq-storage` 프로젝트)에서 SQL을 통해 직접 조회할 수 있으며, UTC 시간의 KST 변환 및 중복 제거 처리가 필요합니다.
- **로그 적재 실패 데이터 확인**: 수집 기준을 충족하지 못한 이벤트는 `t_raw_event_log_rescue` 테이블에 격리되며, `errorReason` 등을 통해 오류 원인을 파악하고 수정할 수 있습니다.

```sql
-- BigQuery 예시: 파티션 및 날짜 조건 조회
SELECT * 
FROM `habq-storage.dataset.t_raw_event_log`
WHERE DATE(dateTime) = '2023-10-13';
```

## # 사업 및 글로벌 서비스 전략 (`예상수익금`, `컴투스플랫폼`)
- **예상 수익금 메트릭**: 결제액에 마켓별 수수료와 세금을 반영한 **예상수익금**을 하루 단위로 제공하여 정산서 발행 전 미리 수익 흐름을 파악할 수 있습니다.
- **글로벌 서비스 교류**: 컴투스플랫폼, 마이넷, 플레이오 등이 참여한 도쿄 세미나를 통해 글로벌 게임 서비스 전략과 노하우를 공유했습니다.
