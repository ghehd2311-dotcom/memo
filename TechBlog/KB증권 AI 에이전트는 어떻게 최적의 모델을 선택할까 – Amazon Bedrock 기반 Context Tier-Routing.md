    ## KB증권 AI 에이전트의 Context Tier-Routing 도입 개요

KB증권은 사내 에이전틱 AI 서비스인 **‘깨비AI’**를 운영하며, 사용자 질의의 복잡도에 따라 최적의 모델을 선택하는 **Tier-Routing** 시스템을 구축했습니다. 모든 질의를 고성능 LLM으로 처리하면 불필요한 비용이 발생하고, 경량 LLM만 사용하면 복잡한 작업에서 품질이 저하되는 문제를 해결하기 위함입니다.

---

## 주요 과제 및 해결 방안

초기에는 단일 질의를 기준으로 난이도를 분류했으나, 멀티턴 대화의 맥락 반영 실패, 에이전트 작업 난이도와의 괴리, 잦은 모델 전환으로 인한 프롬프트 캐시 무효화 등의 한계에 부딪혔습니다. 이를 극복하기 위해 다음과 같은 방식을 도입했습니다.

1. **LLM 호출 단위의 판단**: 최초 사용자 질의뿐만 아니라 **현재 대화 맥락**과 **Tool 실행 상태**를 함께 고려하여 매 LLM 호출 직전마다 난이도를 재판정합니다.
2. **Elevate-only 정책**: 모델이 빈번하게 전환되며 프롬프트 캐시가 무효화되는 것을 방지하기 위해, 한 번 상위 Tier로 올라간 모델은 세션이 끝날 때까지 하향되지 않도록 설정했습니다.

```python
# Elevate-only 정책 예시 개념
if router_prediction_rank >= current_model_rank:
    current_model = router_prediction_model
else:
    current_model = current_model  # 기존 상위 모델 유지
```

## 구현 및 아키텍처

**Amazon Bedrock**과 **Amazon SageMaker AI** 환경을 기반으로 모델 학습 및 추론 파이프라인을 구축했습니다.

- **Feature 추출**: 원본 에이전트 로그에서 현재 사용자 질의(`current_user_query`), 최근 대화 맥락(`recent_context`), Tool 왕복 및 호출 횟수 등의 구조적 특징을 추출합니다.
- **임베딩 모델**: `intfloat/e5-large`를 활용하여 질의와 맥락을 각각 벡터화하고, **XGBoost** 기반의 이진 분류기를 통해 **STANDARD**(자체 서빙 `gemma4-31B-it`)와 **ADVANCED**(`Claude Sonnet 4.6`) 모델을 선택합니다.
- **성능 평가**: 평가 데이터(1,383건) 기준 Accuracy **85.83%**, **ROC-AUC 0.9440**, **PR-AUC 0.9555**를 기록했습니다.

### 1. 주요 성과

- **평균 품질 점수**: 85.6점 → 85.2점 (-0.4점 유지)

- **클라우드 API 비용**: **15.8% 감소**
- **E2E 응답 시간**: 중간 난이도 기준 **29% 단축**

### 2. 한계 및 향후 개선 방향
- **Hard 구간 품질 저하**: 복잡한 투자 판단이나 짧지만 이전 대화 맥락을 유지해야 하는 요청에서 일부 경량 모델이 한계를 보여 품질 점수가 하락했습니다.
- **개선 계획**: ADVANCED 판정 임계값 재조정, 이전 맥락 참조 신호 강화, 운영 지표 추적 등을 검토하고 있습니다.
