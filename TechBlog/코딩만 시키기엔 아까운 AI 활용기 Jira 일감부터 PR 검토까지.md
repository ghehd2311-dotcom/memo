    ## # AI를 활용한 개발 업무 확장과 ‘코드 밖의 일’ 자동화

개발자의 하루는 단순한 코드 작성을 넘어 문서 검토, 프로그램 동작 파악, 설명 작성 등 다양한 **‘코드 밖의 일’**로 채워져 있습니다. 이 글은 AI를 코딩뿐만 아니라 업무 요청 정리, 근거 자료 수집, 코드 구조 시각화 등 다양한 영역에 연결하여 수고를 줄이고 생산성을 높인 경험을 다룹니다.

---

## ## 주요 도구별 활용 사례

### 1. Jira 일감 자동화 (`jira-auto-agent`)
- **개념**: **Jira** 일감을 선택하면 코드 수정부터 검증, 검토 자료 준비, 초안 PR·MR 생성까지 이어지도록 만든 로컬 웹 도구입니다.
- **핵심 기능**: 작업 명세 준비, 코딩 에이전트 연동 구현, 변경 전후 화면 비교, 아키파이(Archify)를 통한 구조 시각화 등을 지원합니다.

### 2. 답변 근거 수집 (`FocusDesk` & `Aside`)
- **개념**: 업무 문의에 필요한 근거를 모아주는 **FocusDesk**와 브라우저 상의 자료를 읽어오는 **Aside**를 **MCP(Model Context Protocol)**로 연결한 도구입니다.
- **핵심 기능**: 개발 완료와 운영 반영 여부를 구분하여 답변 후보와 원문 근거, 추가 확인 사항을 제공합니다.

### 3. 코드 분석 (`REA`)
- **개념**: 낯선 프로젝트나 프로그램의 구조와 동작을 분석하는 **REA(Reverse Engineer Anything)** 도구입니다.
- **핵심 기능**: 전체 코드를 한 번에 이해하려 하기보다 눈에 보이는 특정 동작(예: 버튼 클릭, 미리보기 갱신)을 기준으로 조사 범위를 좁혀 원인과 수정 위치를 파악합니다.

### 4. 설계와 구현 분리 (`Hermes Agent` & `OMX`)
- **개념**: 개인 프로젝트(게임 제작 등)에서 설계를 논의하는 대화와 코드를 고치는 작업을 분리하기 위한 도구 조합입니다.
- **핵심 기능**: **Hermes Agent**로 요구사항과 흐름을 정리하고, **OMX(oh-my-codex)**로 구현 및 검증을 나누어 진행하여 일관된 방향성을 유지합니다.

- **개발자의 역할 변화**: 세부 구현은 AI가 담당하되, **문제를 정의하고, 요구사항을 명확히 전달하며, 결과물의 타당성을 검토하는 판단력**은 온전히 개발자의 몫으로 남습니다.
